ตัวเลขเครื่องคุณ
แบบเรียลไทม์ ลอยบนหน้าจอ

FPS · CPU · GPU · อุณหภูมิ · RAM — อัปเดตทุก 500ms ลากวางตำแหน่งได้อิสระ ปรับสี ขนาด ความโปร่งใสได้ทุกอย่าง

ดาวน์โหลดฟรีเลือกแพลตฟอร์มด้านล่าง ดูว่าค่าไหนอ่านจริงได้บ้าง

ตัวอย่างเคลื่อนไหว — ในแอปจริงคือค่าจากเซนเซอร์เครื่องคุณ

ค่าไหนอ่านได้จริง ค่าไหนต้องมีเงื่อนไข

เราไม่ใส่ตัวเลขหลอกในแอปจริง — ถ้าอ่านค่าไม่ได้ จะโชว์ N/A ตรงๆ

Windows
  • CPU / RAMอ่านจริงทันที
  • CPU / GPU Temp · VRAMอ่านจริง — ต้องรันแบบ Admin
  • FPSอ่านจริง — ต้องติดตั้ง RTSS (ฟรี) ไว้เบื้องหลัง
Android
  • RAMอ่านจริงทันที
  • อุณหภูมิแบตเตอรี่อ่านจริงทันที
  • CPU %อ่านจริงถ้าเครื่อง/ผู้ผลิตไม่บล็อก proc/stat
  • FPS ของเกม / GPU %ไม่มี API สาธารณะแบบไม่ root — ไม่ใส่ค่าหลอก

ปรับแต่งได้ทุกพิกเซล

01

ลากวางตำแหน่งได้

จับที่จุดจับ แล้วย้าย HUD ไปมุมไหนของจอก็ได้ ตำแหน่งจำไว้ให้อัตโนมัติ

02

5 ธีมสี · 3 ขนาด

ปรับให้เข้ากับธีมเกมหรือความชอบ ความโปร่งใสปรับได้ตั้งแต่ 20–100%

03

เลือกเปิด/ปิดทีละค่า

ไม่อยากเห็น RAM ก็ปิดได้ อยากเห็นแค่ FPS กับ TEMP ก็เลือกได้เอง

04

แจ้งเตือนความร้อนสูง

สั่นหรือส่งเสียงเตือนทันทีที่อุณหภูมิเกินเกณฑ์ที่ตั้งไว้

เลือกแพลตฟอร์ม

Windows

Windows 10/11 · .NET 8 SDK

ดาวน์โหลดโปรเจกต์ Windows

ซอร์สโค้ด C# พร้อม build · ต้องมี RTSS สำหรับ FPS จริง · รันแบบ Admin สำหรับอุณหภูมิ

Android

Android 8.0+ · Android Studio

ดาวน์โหลดโปรเจกต์ Android

ซอร์สโค้ด Kotlin พร้อม build · ต้องอนุญาต "แสดงทับแอปอื่น" ครั้งแรกที่เปิดใช้

ทั้งสองไฟล์เป็น โปรเจกต์ซอร์สโค้ดจริง ที่อ่านค่า FPS/CPU/GPU/TEMP จากเซนเซอร์เครื่องจริง — เปิดด้วย Visual Studio (Windows) หรือ Android Studio (Android) แล้วกด build ก่อนใช้งาน รายละเอียดอยู่ใน README.md ข้างในแต่ละโฟลเดอร์
